# New Sale Efficiency Reference

Use this reference before changing or reviewing New Sale, POS, or order-entry UX.

## Common Sale Scenario Template

Document one realistic scenario before and after the change:

- Existing customer or quick-create customer.
- Product or SKU search.
- Add one or more line items.
- Adjust quantity or variant.
- Save quote or create Sales Order.
- Optional payment handoff.

## Efficiency Measures

- Click count: count pointer/touch actions excluding text typing.
- Dialog count: count modal, drawer, popover, and confirmation surfaces that interrupt flow.
- Route transitions: count full route changes required to finish the sale.
- Time target: common sales should remain approximately 30-60 seconds.

## Layout Checks

- Desktop: dense and scannable, keyboard friendly.
- iPad landscape: primary workflow visible without cramped controls.
- iPad portrait: line items, totals, and primary action remain reachable.
- Mobile: usable for lookup and review, even if desktop/iPad are primary.

## Preferred Interaction Shape

Keep search, quick create, product entry, line editing, and save actions in one coherent work surface. Move rare administrative fields behind disclosure controls, not into the common path.
